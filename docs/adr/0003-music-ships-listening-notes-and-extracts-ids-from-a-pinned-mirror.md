# Music Ships Our Listening Notes and Measurements, and Extracts Its Ids From a Pinned Mirror

The music search tool (sc2-adjutant#701) joins two things by file base name, as the doodad catalog does (ADR 0001). The notes are ours and ship; the ids and files are the game's and are extracted into each user's cache.

**Ships, under CC BY 4.0, in `data/music-notes.json`:** Gemini's listening notes (its description, mood, tension, valence, energy, instrumentation, sections with start times, what the track suits and what to avoid) and our measurements of each file (length, loudness, tempo estimate, onset rate, fades, where it peaks, whether it is silent). Gemini heard each file with no name, game or context. The measurements have to ship: the finder searches with no install and no audio, and a length filter and an energy score can only come from the audio. A note is one line, keyed by the file's base name as Blizzard names it (`Music_DarkVictory_Full`, so the key is a game file name that ships; the join needs it, as the audio is found by it), matched without regard to case. One rule makes a key from a path, `musicFileName`: the last path segment without a `.` and one to four letters or digits at its end, used by the builder and the join alike. Where one file sits in two folders, one note stands. `scripts/build-music-notes.mjs` makes the file from sc2-adjutant's research catalogue; nothing in it names a campaign, mission or story, and a test fails on any field that isn't ours.

**Never ships:** audio, albums, composers, the wiki's and Blizzard's pages' descriptions, and anything extracted from the game.

**Extracted by `extract-music`:** one record for every id a map can play music with, 1,354 of them: 923 Soundtracks and 431 Music-category Sounds no Soundtrack plays (19 ids are both). Each has where it is defined, the package that defines it last, the dependency a map needs, its files, a role worked out from its id, whether it is empty, and where Blizzard's scripts and cutscenes name it. A map-local id, one that exists only inside one Blizzard map, says which. The data comes from sc2-arcade-watcher/sc2-game-data at one pinned commit, not from SC2GameData: the usage scan reads the campaigns' map scripts and cutscenes, which SC2GameData doesn't hold. The files are about 900 small ones, fetched in a quarter of a minute after a listing of the commit's files by GitHub's API or, when that refuses, by git.

**Joined by base name.** An id is an entry with the notes of the files it plays. An id whose files have no notes is still an entry, found by the words of its id. A note whose file no id plays is left out and reported. An id is map-local, hidden by default, only when every definition of it is in that one map; one a campaign or mod also defines is playable from any map and takes the dependency of the last definition outside a map.

**How the keyword search weighs words.** A word counts by how few entries say it (its inverse document frequency over every entry, counted once per catalog), so one rare word of an ask ("alarm", in 33 entries) outweighs several common ones ("builds", in 536, "sounds", in 403): the stemmer keeps five letters, so each of those matches a third to a half of the catalog. Function words are ignored outright. An id is scored by its best file's notes, not by the words of all its files together. 119 ids play more than five noted files, and for a countdown ask 82 of the top 100 results were such pools, because the union of fifty files' words matches nearly any ask and crowded out the 970 ids with one file. Even so, a pool can hold one file that fits, so pools still reach the top (56 of 100 for that ask), and a track that only a pool plays can't rank far above the pool's other files. Whether an id should instead be scored by how many of its files fit (what a random pick would play) is open.

## Considered Options

- **Compute the measurements in the finder from the user's audio.** Rejected. Without an extracted audio folder there'd be no length or energy filter, and extracting the audio is the one step a mapper has to do by hand.
- **Read SC2GameData for the music too.** Rejected. It holds mods and campaigns but not the maps, whose scripts hold most of the places music is used.
- **Key a record by id alone.** Rejected. Nineteen ids are both a Soundtrack and a Sound, and the two play different things.
